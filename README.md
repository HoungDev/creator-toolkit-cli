# Creator Toolkit CLI

A modern Python command-line toolkit for creators and developers.

## Features

- Generate titles
- Generate tags
- Rename image files
- Export data to JSON

## Project Structure

```
creator-toolkit-cli/
├── docs/
├── src/
├── tests/
├── README.md
├── pyproject.toml
└── .gitignore
```

## Requirements

- Python 3.13+
- Git

## Installation

```bash
git clone https://github.com/HoungDev/creator-toolkit-cli.git
cd creator-toolkit-cli
```
