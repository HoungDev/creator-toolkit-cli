# Creator Toolkit CLI

![Python CI](https://github.com/HoungDev/creator-toolkit-cli/actions/workflows/python-ci.yml/badge.svg)

A modern Python command-line toolkit for creators and developers.

## Features

- Generate titles
- Generate tags
- Rename image files
- Command-line interface (CLI)

```
creator-toolkit-cli/

```

## Requirements

- Python 3.13+
- Git

## Usage

Run the application:

```bash
creator-toolkit
```

1. Generate title
